# 四码前缀与重叠尾段的正确率乘积

独立实验情景，按本次指定的简单规则计算，不使用段位强度参数或总成本单调护栏。原生二至四码成本保持冻结值。当前结果是模型一致性检查，尚无五、六码真人校准。

## 正确率定义

对 `ABCDE` 与 `ABCDEF`：

```text
Q5(ABCDE)  = Q4(ABCD) * Q2(DE)
Q6(ABCDEF) = Q4(ABCD) * Q3(DEF)
P = 1 - Q
```

重叠的第四键 D 只用作下一次转换的锚点，不重复按。四码部分覆盖 A→B、B→C、C→D；尾段覆盖 D→E，或 D→E、E→F，不漏掉组间转换。

原生短串正确率由条件段风险合成：`Q2 = 1-h_L2i1`，`Q3 = (1-h_L3i1)*(1-h_L3i2)`，四码同理使用三个四码角色。训练只记录首错前的事件，且首键即错不进入键对样本；这些概率条件于首键正确，并非包含第一键错误的完整试次概率。

严格的链式公式需要“前缀成功条件下的尾段正确率”。这里用已有独立短串任务的二／三码预测近似这个条件概率；这是分块模型的简化假设，不是已实测的条件等价关系。所有错误表均按冻结上游源码／数据重建，未与原始分项错误产物逐位核验。

## 成本衔接

冻结模型的四码错误成本按段风险求和，不等于 `782.2*P4`。为保持二至四码原值，本实验采用增量锚定：

```text
H4 = sum(ABCD 的三个原生段风险)
Hrolling = sum(原有长串滚动段风险)
Tinferred = Clegacy - 782.2 * Hrolling
Cnew = Tinferred + 782.2 * (H4 + P_long - P4)
```

即保留四码已有错误成本，新增错误风险只按 `P_long-P4` 计费；时间部分继续使用原有滚动上下文。`Tinferred` 是从重建错误表推得的时间部分，不声称精确还原上游原始时间分表。整体单调性需要单独检查，不能仅从错误概率的性质推出。

## 冻结表的数值检查

二至四码共 837,900 个原生 30 键组合的成本、元数据逐项保持一致。

固定种子 `20261120`，每行 100,000 条，共 400,000 条；以下是预测总成本下降的数量：

| 抽样域 | 长度 | 冻结延拓 | 正确率分块乘积 | 逐键条件尾段对照 |
|---|---:|---:|---:|---:|
| 30 键均匀 | 5 | 60 | 0 | 0 |
| 30 键均匀 | 6 | 69 | 0 | 0 |
| 21 声韵键＋物理形辅 | 5 | 124 | 0 | 0 |
| 21 声韵键＋物理形辅 | 6 | 232 | 0 | 0 |

还可以对当前表给出全域数值下界，无须穷举所有五、六码：穷举 810,000 个末四键上下文，推得每次延长的最小时间增量为 16.498943795 ms。穷举 27,000 个尾三码，`P3-P2` 最小为 −0.004836958472。因此：

```text
C5-C4 >= 16.498943795 ms
C6-C5 >= 16.498943795 + 782.2 * min(0, min(P3-P2))
       >= 12.715474878 ms
```

这是当前冻结表和重建错误表下的模型下界，不是真人耗时的物理定律。

`YYWX` 保持 598.831070 ms，`YYWXO` 在分块情景中为 635.921116 ms；对应条件整串错误概率为 14.366610% 与 14.647740%。增加 O 后，模型不再大幅调低四码前缀的风险。

## 六码与五码的概率差异

两个长串的错误概率都保证不低于其四码前缀。但原生尾段 `Q3(DEF)` 不一定小于 `Q2(DE)`：27,000 个尾三码中有 55 个错误概率下降。这里说的是错误概率，与此前二→三、三→四的**总成本**无反转不矛盾。

因此原指定公式在两组六码抽样中仍分别有 193、1,158 个“错误概率比五码低”的情况，尽管总成本均增加。为了区分这两项要求，另提供显式选择的逐键对照：

```text
Q5 = Q4 * (1-h_L2i1(DE))
Q6 = Q5 * (1-h_L3i2(DEF))
```

它固定第五键已有风险，仅追加第六键的条件成功率；保证 `P6>=P5>=P4`，且没有人为概率抬底或总成本护栏。两种方案分别报告，不悄悄替换指定的三码整段乘积。
