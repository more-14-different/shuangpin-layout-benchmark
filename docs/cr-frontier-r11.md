τ=600、首辅/次辅=300 ms，页面滑杆仍实时重算相应列。

替代规则数。转换时验证该公式与正式 memoryAudit 一致。韵组成员按正式
`finals` 列表还原，包含重新分组的 in/vn；不能仅按 roots 标签推断。
`shapeKeysByMeaning=AVUIO`，`toneKeysByTone=IVUAO`，语义配对仍为 42310。

页面通过独立带调注册表接入，保留原无调条目的完整语义。四个方案出现在方案
筛选、基准表、公平表、碰撞表、文章回放和跨合同报告中；支持数值排序、CSV、
当前环境重算和 M/D/负载筛选。详情复用合并键盘、总热力图及统一字词／全拼筛选，
各方案韵组颜色跨排一致，声母移位遵循统一 OKLab 链约束。

运行 `just cr-frontier-benchmark` 逐方案串行重算并发布到本地
`a7_CKT_R11.html`；`just cr-frontier-benchmark-test` 验证正式映射转换、
页面联动和全部方案配色。需要现有 R11 语料、Snow 字典与
`research/.cache/ckt-v51-toned-mars10-D1-final.json` 基准夹具。
`--reuse-scores` 只复用已生成的 native/columns 文件，发布前仍验证各自 ID、
码表 SHA256、三项原审计锚点与记忆账。重新生成原冰雪剑道时会保留 CR 注册表。

HTML 与完整本地中间文件按仓库规则忽略；计算脚本、逐列数值审计、文档和测试纳入版本控制。
