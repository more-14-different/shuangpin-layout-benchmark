## NF3 证书范围

每个父种固定实际 M、逻辑声韵分组、重码桶、五辅集合与顺序。接受端点保持父种的 CKT-S2、v5、v4 上限；含重码父种同时保持补全、C4-Snow 与两种 Snow 词尾形序上限。

七类邻域为：第一码两交换、第二码两交换、第一码三循环、第二码三循环、声韵各换一对的原子联动、含 zh/ch/sh 或零声母载体的第一码四循环、同类四键集的两对不相交第一码交换。

证书确认这些有限邻域在声明目标下达到局部闭合。开放方向列于 HTML 探索地图和 README。
