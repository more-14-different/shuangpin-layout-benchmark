# UM40 大范围韵侧扰动 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Continue the user's authorized experiment inline.

**Goal:** 冻结 UM40 声母，跨越上一轮局部极小，尝试在默认/加倍认知成本下超过 R2。

**Architecture:** 沿用已验分的完整 CKT5.2 内核及 18 根韵/10 非空组模型。先对组号规范化消除等价状态，再运行双目标多温度、多起点随机退火，混合根韵迁移/交换/循环、行键交换/循环/合并重分配、多步扰动及跨候选组合，最后完整单步下降及 144 辅序独立复核。

**Tech Stack:** Python/NumPy/Numba、Node、PowerShell。12 CPU 工作者，低优先级，检查点续跑。

**Spec:** 用户“继续大范围扰动韵间和韵内，看看可否超过r2”；沿用已确认固定 UM40 声母、上二三/中四/下一轻。

## Global Constraints

- 所有声母不变；D3、实际韵键10/9/7；根韵完整，所有10组非空。M不额外设限，模型自然上限22/22。
- shapeKeysByMeaning=AEUIO、toneKeysByTone=IEUAO、配对不变量42310；默认/加倍均重算参考分。
- 比较 R2 默认8.640932204060537、加倍8.234488645251973；同四轨1:3:1:1合同。
- 不筛左右小指；不改HTML；不得把随机探索说成穷举或全局最优。
