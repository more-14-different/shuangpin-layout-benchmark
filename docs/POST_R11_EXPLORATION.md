# R11 之后的多级探索路线（2026-10-02—2026-11-01）

本文把 R11 冻结后散落在 feature、experiment 与 production 分支中的探索按时间重组，回答三个问题：我们怎样逐层缩小搜索空间、哪些区域已经投入过算力、哪些结论可以复用或需要重新验证。

> 口径边界：R11 页面中的“补全 CKT ms”与后续归一化的 **CKT v4（S005 = 10，越低越好）不是同一数值轴**。下文不把后续结果并入 R11 冻结榜单。文中的 P0—P8 只是本回顾使用的阶段标签，不是新的 R12/R13 发布编号。

## 路线总览

```text
R11 冻结页
  └─ P0 统一碰撞/补全模型（CKT v3）
      └─ P1 CKT v4 精确 CPU 真值、联合池、约束邻域、人体工学来源
          └─ P2 SQLite 代际避重 + 多目标选种 + CUDA 精确全量评分
              ├─ 21×21 路线
              │   ├─ P3 M/D 逐层下降与低温微调
              │   └─ P4 固定 IVUAO、ProdGate、全候选盆地复核
              │       └─ P7 U357 的 M<40 严格不退化下界实验
              └─ 21×26 路线
                  ├─ P5 宽口径低 V 速度地形
                  ├─ P6 D 的可行下界与 D≤1 跨盆地复核
                  └─ P8 放宽到 D≤3 的速度前沿
```

这条路线的核心不是连续追一个最低分，而是先建立可逐项验证的评分与恢复机制，再用“宽域定位 → 约束收紧 → 生产门禁 → 跨盆地复核 → 改变约束”的方式分层探索。

## 关键转折与结论层级

### 1. 先校准方法，再扩算力

P0—P2 解决的是“同一个布局是否会被不同实现算成同一个结果”。CKT v4 把语料行、候选竞争、运动代价和认知项固定为可复核合同；Rust CPU 是运行时精确真值，JS 用于跨实现回归，CUDA 只接管保持精确等价的全量解析。后续生产轮次因此可以共享状态键、检查点、SQLite 档案和 Pareto 合并逻辑。

最初的 CUDA 单候选 resolver 有 3.43× 局部加速，但短退火端到端只有 1.24×；简单 8-lane 排序也曾在 0.84×—1.08× 间摇摆。把活动项构造、逐行阶段推进与 finalists 压缩融合后，resolver 才取得稳定结构性收益。这个负结果值得保留：只扩大 batch、而不迁移主机侧瓶颈，不会自动得到吞吐提升。

### 2. 21×21：从速度地形到生产地形

P3 的逐级收紧先确认低 M/低 D 的速度沟壑存在，并暴露出跨阶段必须桥接上一层前沿。P4 固定 IVUAO 后，Stage 5 的 127,982 个不同状态一度得到“更快且全门禁合格 = 0”的负结果；继续采用 24 小时分级接力与专门的 ProdGate 后，最终得到 66,036 个同时快于旧基线且通过门禁的状态，说明“有限轮未找到”不能当成不可行证明。

随后把 Astra 7 的 43 个同口径历史候选按 Hamming 半径 5 归成 23 个代表盆地，用 3 个独立 `baseSeed` 和共享避重档案再探索 11,280 个状态，未改善裸速度 9.635205 与 ProdGate 9.705581。它支持在**现有算子、种子和合同下封盘**，但不构成对整个组合空间的穷举证明。

ProdGate 定向修复还建立了 U=353—359 的合规 Pareto 带。发布 U357 的 CKT v4 为 9.716421、M40/D0/V5；U359 能减少音节碰撞，但 CKT 为 9.742204。二者是“速度—唯一音节码—人体工学”的取舍，不应只按一个分数排序。

### 3. 21×26：先画宽域，再证明下界，再放宽

P5 先以 M≤46、D≤10、V≤1 画出宽域速度地形，得到 8.949768 的参考极值。P6 再把区域收紧到 M≤40、D≤1、V≤1：固定五辅占据元音键后，18 个自然声母占 18 个辅音键，余下 3 键无法容纳相互冲突的 `zh/ch/sh/Y` 四组，因此 D=0 不可行，D≥1 是结构下界。

在 D≤1 内，主跑和两组独立跨盆地验证都回到 9.167862；继续重复同样的 400 代合同收益很低。P8 没有继续堆代数，而是把约束改为 D≤3，在第 79 代到达 9.050693，说明改变搜索区域比在已饱和盆地追加预算更有效。P5/P6/P8 都没有 21×21 那套完整 ProdGate，因此它们回答的是速度地形问题，不是人体工学投产问题。

### 4. U357 的负结果属于可证明下界

P7 与普通“没搜到”不同。在固定 IVUAO、传统五辅/韵母隔离、D=0、CKT 与全部人体工学均不得退化的条件下，M39 唯一可能减少的记忆项要求零声母 `W` 回到 W 键；但该 token 单独造成的 W 峰值 `0.058176` 已高于 U357 的整键上限 `0.036232`。其他 token 负载非负，因此继续扩大退火也无法绕过该下界。

这个证明只对上述合同成立。允许更换五辅、五辅兼作韵母或放宽 W 峰值时，问题会变成新的 Pareto 搜索。

| 21×21，严格 IVUAO，M40/D0/V≤5 | 多阶段、ProdGate、23 盆地、3 baseSeed 已深挖 | 同一合同下不要只重复加代；优先更换提案算子、门禁或独立语料 |

仍未闭合的高价值问题包括：21×26 的完整生产人体工学门禁；D=2 独立切面；真实用户实验；跨语料稳健性；以及能否用路径重连、自适应提案或不同拓扑突破当前经验平台。除 U357 M40 下界与 21×26 D≥1 外，本文所有“封盘”都应理解为冻结搜索合同下的经验决策。

## 方法模板

后续轮次可复用以下最小闭环：

1. 冻结语料、评分版本、拓扑、M/D/V 与人体工学门禁，写入 `run-contract.json`。
2. 用 CPU/JS 参考反验起始方案；GPU 只能作为逐项等价的加速后端。
3. 宽口径确定速度地形，再逐级收紧；每次收紧都保留上一层的属性极点和远距种子。
4. SQLite 以紧凑状态键避重；按 CKT、M/D/V、负载、主行、MX 和布局距离选 8 个左右代表种子。
5. 至少使用多个盆地和独立 `baseSeed` 做短程复核；记录“连续多少代/多少新状态未突破”，而不是只写“收敛”。
6. 将结论标成数学证明、经验饱和或有限搜索负结果；若改变任一合同，重新开轮，不沿用旧封盘结论。
