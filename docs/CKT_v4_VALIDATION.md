日期：2026-10-15。结论先行：**路由与联合候选池模型已经达到可测试、可复现状态；认知系数还不能定案，因此暂不替换 HTML 中的 CKT v3 排名。**

## 已确认并修复的 v3 问题

1. v3 文档写“二、四字词同台”，实现却按 `character/word2/word3/word4` 分别建候选桶，跨词长碰撞实际没有进入分数。
2. v3 的二字词不是宣称的冰雪约 13 万全量词，而是页面内两个 6 万外部词表的并集再过滤，实际约 6 万。
3. 非 21×21 三字词被当作 `AAA→AAAB→AAABB`；实际四码顶路由是 `AAA→AAAU→AAAUB→AAAUBB`，且只有 `AAA` 残余项进入二/三/四字联合池。
4. v3 用旧上游快照，且把 5/6 键物理外推和视觉认知惩罚揉在一个公式里。

## 发布判断

当前可以据此停止用 v3 继续产生新的“最终前沿”，并用 v4 原型做双轨复核；尚不应该把 v4 写回 HTML 成为唯一排序。下一门槛是：

1. 对 95%/99%/99.5% 语料质量和多音词合并口径做排名稳定性；
2. 在认知参数网格下跑全 840 方案，报告 Spearman、Top-N 交集与前沿翻转；
3. 采集辅码回忆、候选视觉搜索和选重实验，拟合认知层；
4. 为 `[]\'` 做原生实测，或在榜单中长期把含扩展键方案标为“投影口径”。
