## 本地立项档案

1. 方案结论：完整码表与冻结指标。
2. 搜索结论：父种、预算、约束、轨迹和闭合证书。
3. 来源说明：上游配置、作者文档与具体快照。
4. 立项历史：聊天档案，用于解释问题从何而来。
