# CKT v5.2：继承各方案合同的长串错误率延拓

v5.2 仅更换五、六码的错误损失延拓，完整继承每项已发布 v5.1 的任务定义。它不是把所有方案统一套用一个码路。原 v5.1 数据与列保留，v5.2 紧邻显示。

## 成本模型

以 Q 表示原生短串预测正确率，P=1−Q：

```text
Q5(ABCDE)  = Q4(ABCD) × Q2(DE)
Q6(ABCDEF) = Q4(ABCD) × Q3(DEF)
```

第四键 D 是尾段上下文锚点，只按一次。原生二至四码成本不变；五、六码继续使用原有滚动时间模型。冻结四码的错误成本按条件段风险求和，因此不能直接用整串错误概率替换：

```text
H4       = 四码前缀的原生条件段风险之和
Hrolling = 原有长串滚动条件段风险之和
C5.2     = C5.1 + 782.2 ms × (H4 + P长串 − P4 − Hrolling)
```

实现使用直接乘法。对数表示在数学上等价，此处没有计算速度或精度优势。没有额外的耗时抬底、单调护栏或段位折减参数。

错误率表从冻结上游源码和数据重建，未取得原始独立错误分表；这仍是模型外推，未经真人五、六码校准。短串概率条件于首键正确。已有短串任务的尾段预测用于近似“前缀成功条件下的尾段正确率”，不是实测条件概率。当前冻结表的总成本延长下界为四→五 +16.498943795 ms、五→六 +12.715474878 ms；少量三码尾段的错误概率可低于其二码前缀，不影响该表下总成本增加。详细数值审计见 [CKT_BLOCK_ERROR.md](CKT_BLOCK_ERROR.md)。

## 继承范围

每个方案保留自己的声韵映射、物理形辅／调辅语义、生产辅序、候选集、候选池竞争、分页、认知参数与词长路线。不会因更新成本模型而重新挑选辅序。

* 无调 21×21：单字独立；二／四字词联合竞争；三字词按三声母、三辅码的独立合同计算。
* 无调 21×26：单字独立；二／三／四字词联合竞争；三字词保留 AAA→AAAU→AAAUB→AAAUBB 路线及软长度均衡。
* 带调主码 21×21、21×26：分别保留发布时的原生主码、形辅终码、辅序与各词长候选合同。声调已进入主码，后续只有形辅，不虚构调辅成员。

本次重计价保留已选定终码。无调方案的长串阶段必须只有一个物理码，程序遇到多备选长码即拒绝运行；短串多备选成本保持原值。原生带调终码逐项核对原运动成本、词条数与总频重。f19 的完整候选重建验证另见前述数值审计。

形辅为 `keytao`，调辅为 `sanpin`。`entry.tone` 始终表示按一、二、三、四、轻声排列的 `toneKeysByTone`，形辅键按 `auxiliary_semantics.js` 派生。保留 `42310` 配对语义。

## 归一与详情

对模式 m、词长轨 k，令 T 为包含原认知成本的有效耗时，R 为 S005 的同模式、同词长有效耗时。S005 的形辅、调辅使用各自原 v5.1 参考辅序，也同步计算 v5.2。

```text
单轨分 = 10 × T[m,k] / R[m,k]
总分   = 10 × (Σm Σk w[k] × (T[m,k]/R[m,k])^4 / (6 × 成员数))^(1/4)
w[单字,二字词,三字词,四字词] = [1,3,1,1]
```

无调方案两个成员各半；各半先按各成员的参考值归一，再合成四次幂。不能先平均耗时再归一。带调主码沿用原合同，仅有形辅成员。详情列出每个成员和各半的总分，以及单字、二／三／四字词各自的路线、辅序、有效耗时和单轨分。各半的耗时均值仅用于描述，不用于代替分数公式。
