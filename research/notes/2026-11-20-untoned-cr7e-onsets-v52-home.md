# 高频声母向主行集中且保持 D2 的布局探索

本轮保持 **D 恰好为 2、M 为 41 或 42**，按声母频率引导迁键，并联合调整翘舌与韵母。新增精算 5,724 个布局，找到 W→F、f→W、k→P 的新声母中心，但其 CKT v5.2 仍未超过前序 U7E 与 U7R 前沿。

## 频率与预算

频率来自既有 Common399 音节权重。它用于筛选迁键方向，不等同于按完整 CKT 词长、候选消歧路径加权后的按键频率。Y/W 指零声母类别。

| 声母类别 | 权重占比 | 本轮迁键方向 |
|---|---:|---|
| Y | 9.437% | 与 F/K/S 上的普通声母联动 |
| x | 5.262% | 与 f/k/s 交换 |
| b | 4.421% | 与 f/k/s 交换 |
| t | 3.857% | 与 f/k/s 交换 |
| W | 3.772% | 与 F/K/S 上的普通声母联动 |
| f | 2.531% | 候选迁出主行 |
| k | 1.888% | 候选迁出主行 |
| s | 1.713% | 候选迁出主行 |

普通声母迁键前恢复原普通声母移位，再分配 D 预算，避免无意叠加到 D4。x/b/t 与 f/k/s 的交换正好占用 D2。

Y/W 的迁键不计入普通声母 D，但会计入 M。将 Y/W 与 f/k/s 交换后，再保留 k→P 或 s→C 中不冲突的一项，普通声母仍恰好移位两个。A/E/O 合并回 R，省出的载键记忆支付 Y/W 的新映射，使总 M 为 42。这是本轮领先方向区别于普通声母纯交换的预算安排。

所有实测布局保持 Common399、实际 21×21、无分支、QZ/ZQ 双空桶、V≤5。辅键保留集合为 AVUIO，`toneKeysByTone=IVUAO`、`shapeKeysByMeaning=AVUIO`，配对不变量 42310。

## 分配与下降范围

采用七个韵母及载键起点：旧 U7E 两个前沿、UED-18c004bd1f31、两套 A42 前沿，以及两套 U7R 前沿。每个起点包含九种普通声母交换和八种 Y/W 联动，共 119 个分配组。

每组枚举 zh/ch/sh 在 E、S、D、F、G、H、J、K、L 上的不同键分配，并要求包含 E，共 168 种。按起点与分配组计，生成 19,992 个组合，其中 12,936 个合法。每组按五种运动与碰撞代理权重各取首位，再以固定种子随机补充到八个，合计 952 次精算选择；重复物理映射复用分数。这不是所有翘舌组合的完整精算。

初筛两个成本点都由 W/f 配合 k→P 的方向领先。随后完成四个领跑点的完整邻域，包含单韵母移动、双韵母交换、整键韵母分组交换，以及 A/E/O 单类或当前共键类别的整体迁移。下降全过程仍要求 D2、M41/M42。

固定搜索辅序为键道 `12/231/24`、三拼 `12/213/23`，三段依次为二、三、四字词。CKT v5.2 的参考、形调各半、1:3:1:1 词长权重与四次幂合成沿用前序；2 倍成本同时重定价六项认知成本及参考，不倍增运动耗时。

## 最优辅序下的结果

两个成本轴各取前两名，共四个布局。每个布局的键道与三拼分别完整枚举 144 种辅序；两个成本点的最优辅序均与固定搜索辅序相同。以下两列均为各布局在对应成本点的最优值。

|---|---:|---:|---:|---:|
| ONH-51377d089680 | 2 | 42 | **9.565633656** | 9.566478658 |
| ONH-010f5cb16c9b | 2 | 42 | 9.565707911 | 9.566687716 |

四个新入围点共享声母配置：普通移位 **f→W、k→P**，零声母 **W→F、A/E/O→R**，翘舌 **zh→K、ch→S、sh→E**；其余保持普通本位映射及原 Y 类映射。Python 独立 M-R2 审计确认普通声母移位两份、翘舌三份、W 映射一份、A/E/O 载键一份、韵母映射 35 份，共 M42。

1 倍新前沿相对前序 U7E 的 1 倍前沿高 0.013919745，相对 U7R 的对应最优值高 0.036174298。2 倍新前沿相对前序 U7E 的 2 倍前沿高 0.029171347，相对 U7R 的对应最优值高 0.038655489。因此本轮新布局不替换既有性能前沿。

## 迁入主行的收益与边界

按 Common399 音节权重计算声母首键落在主行的比例：

| 声母配置 | 首键主行占比 |
|---|---:|
| 前序 U7E A42 配置 | 45.396354% |
| 新 W/f 配置 | 46.429238% |
| U7R-143cf16e1fa2 配置 | 47.397177% |

新配置比前序 U7E 高约 1.03 个百分点，但仍低于 U7R。此指标只计声母首键，不是完整输入串的主行占比。

初筛中，将 W/f 联动与 k→P 配合优于本轮测试的 W/f 与 s→C 配合；普通声母 x/b/t 与 f/k/s 的纯交换也未直接进入领跑。说明在当前候选池和分组下，保留哪些普通声母移位、合键后如何分桶，与主行频率同样影响综合性能。Y 类权重最高，但本轮抽样并未因此胜出，不能只按声母频率排序预测最终 CKT。

W/f 起点固定辅序为 9.568028829 / 9.572775784；ua/uang 等韵母联动及 in/ui/un/vn 分组变化使其形成两个成本前沿。1 倍与 2 倍领跑点均已完成同一固定辅序下的上述一步邻域，未找到进一步下降点；不包含普通声母或翘舌再次变化的完整邻域证明。

## 复核与复现

新增精算布局共 5,724 个，其中 M41 为 228 个、M42 为 5,496 个，均为 D2。独立重建 119 个筛选组及四个完整邻域，覆盖 5,724 个不同实测布局，记录无漏项。四个入围点经独立 Python 记忆审计、规范 JS 与原生逐项复算，最大分项差约 1.14×10⁻¹³；相关 13 项测试通过。Python 另外从完整辅序组件重新计算两个成本点的最优值。

辅序为各成本点最优辅序，不是宽扰动下的稳健辅序。声母分配与翘舌组合只作有限筛选，不能据此证明“高频进主行”的全部路线无改善空间。生产与 HTML 未改动。
