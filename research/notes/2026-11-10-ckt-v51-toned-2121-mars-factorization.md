# 火星声韵拆分在 AVUIO 7:8:6 下的初探

日期：2026-11-10

## 来源与转写

来源为 [`macroxue/shuangpin`](https://github.com/macroxue/shuangpin) 的
`mars火星/mars.schema.yaml`，固定到上游提交
`cd74b9505c6b4bf905466d6f7ecb6bcf10ab5caf`。上游规则说明第一码为声母，
第二码为韵母加声调；复韵母忽略 i/u/ü 韵头，其中 iu/ui/un 按
iou/uei/uen 还原后分别落到 ou/ei/en。

| 火星韵列 | 本研究完整韵母 |
|---|---|
| `a-ou` | a, ia, ua, ou, iou |
| `en-n` | en, in, uen, vn |
| `e-ei` | e, ie, ve, ei, uei |
| `eng-ai-v` | eng, ing, ueng, v, ai, uai |
| `an` | an, ian, uan, van |
| `ang` | ang, iang, uang |
| `u` | u |
| `i-er` | i, er |
| `o-ong` | o, io, uo, ong, iong |
| `ao` | ao, iao |

37 个完整韵母全部且仅被覆盖一次。第一码有 23 个语义组：20 个单字母声母，
加 zh/ch/sh；零声母与 r 同组。AVUIO 只剩 21 个声键，因此初始 D0 适配把
z/zh、c/ch、s/sh、r/零声母各自同键。随后发现 E 是唯一未占声键，故另测
`zh→E`、`ch→E`、`sh→E`；其中 `zh→E` 也正是上游火星原映射。

## M 口径

Mars10 的临时 M 继续沿用本分支的“规则数 lower / 关联链接 guard”双口径，
不等同于 QZ 的 M-R2：

- 声母侧固定记 4 个特殊组：zh、ch、sh、零声母；`zh→E` 只是替换 zh 的位置，
  不额外增加 M；
- “复韵母删去韵头”记 1 条通则；
- 删韵头后有 18 个根形，6 个多根同列组按规则计 6，按二元链接计 8；
- 10 韵分别进入 7/8/6 调区，最少花 `3+2+4=9` 个区内归并链接。

所以火星 `zh→E` 前沿为：

```text
M_lower = 4 + 1 + 6 + 9 = 20
M_guard = 4 + 1 + 8 + 9 = 22
D/F = 1/1
```

## 四路消融

统一条件为 AVUIO、上/中/下 `7:8:6`、四声/二三声/一零声、固定词辅
`12/213/24`。前三路和 `zh→E` 路线各做 512 个确定性多起点韵布局粗筛，
`_v→M` 路线做 768 个；再以 1,800 条/轨样本筛选，并对前 3～8 名执行完整
CKT v5.1 复算。

| 第一码 | 第二码 | CKT v5.1 | M lower/guard | D/F | 桶 |
|---|---|---:|---:|---:|---:|
| 火星 D0 书写声母 | Mars10 | 9.939534068 | 20/22 | 0/0 | 420 |
| 火星 D0 书写声母 | Pindu11 | 10.071306034 | 19/19 | 0/0 | 415 |
| Pindu 55 声介 | Mars10 | 9.574367279 | 30/37 | 9/9 | 436 |
| Pindu 55 声介＋`_v→M` | Mars10 | 9.568525571 | 31/38 | 9/9 | 432 |
| **火星书写声母＋`zh→E`** | **Mars10** | **9.556530457** | **20/22** | **1/1** | **441** |

消融结论很清楚：

1. Mars10 韵侧本身不差；配合原 Pindu 声介时，它比 Pindu11 基线
   `9.589470270` 更快。
2. 把 55 声介全部压回 23 个书写声母组会损失大量区分度；D0 火星路线因此很慢。
3. 只把高价值的 zh 从 z 中拆到空闲 E，桶占用从 420 达到 441，完整 CKT 直接
   降到 `9.556530457`。ch 或 sh 单拆仅分别到 `9.791642083`、`9.735271268`。
4. `zh→E + Mars10` 与当前 `_v→M + Pindu11` 的 `9.556498964` 仅差
   `0.000031493`，可视为同速；但前者 M 和 D/F 明显更低。
5. 它仍未击败历史 M21 `9.541521260`，差 `0.015009197`，所以当前定位是新的
   低复杂度生产前沿，而不是 CKT 全局冠军。

## Rust v3 的受控邻域

后续长期搜索不再把 55 个声介当作可独立移动原子。第一码先合并为完整声母／零声母
族，只开放 `zh/ch/sh、Y/W、A/E/O` 八类；普通单字母声母冻结。`zhi…zhu…`、
所有 y 开头、所有 w 开头以及 A/E/O 各族都必须整体移动，禁止族内飞键。

韵侧只开放十个 Mars 韵组在三个调区内的整组换键，暂不拆开任何组内完整韵母。
结果另外记录 `firstGroupMoves`、`rhymeGroupMoves` 和恒为零的
`rhymeInternalSplits`。旧报告把 `zh→E` 折入 z 的 D/F，得到 1/1；v3 按生产
21×21 的分层视角把卷舌与零声母视为特殊族，普通单字母声母 D/F 基线为 0/0。
两种口径必须并列说明，不能把历史 1/1 静默改写成同一指标下的 0/0。

`proposal_space` 可取 `first`、`rhyme` 或 `joint`。v3 checkpoint 与 v2 不兼容，
文件名已隔离；换到长期机时必须从 v3 新任务开始，不能续跑旧 checkpoint。

## 完整一跳粗筛（340 候选）与二跳全量穷举（653 候选）

基线得分 `9.5565304573`，历史 M21 标杆 `9.541521260`。
普通单字母声母新口径 D/F = 0/0（历史折叠口径 1/1），`rhymeInternalSplits = 0`。

### 1. 一跳 340 候选穷举审计（声 160 + 韵 180）
- **声侧极限**：`sh → P`（`9.4811320987`，ΔBase = -0.0754，ΔM21 = -0.0604，M 20/22，D/F 0/0）
- **韵侧极限**：`u(upper) → P`（`9.5258074390`，ΔBase = -0.0307，ΔM21 = -0.0157，M 20/22，D/F 0/0）
- **前沿结论**：声韵两极分别由 `sh → P` 和 `u(upper) → P` 构成 1-hop Pareto 前沿。

### 2. 二跳 653 候选全量穷举审计（Pareto 双种子展开）
以 1-hop Pareto 的两个代表方案为基底，穷举全部 653 个互补二跳组合：
- **全局最优（声侧＋韵侧协同）**：
  - `sh → P`（特殊族首码）＋ `u(home) → K`（火星韵组二三声中排换键）
  - CKT：**`9.4514302425`**（ΔBase = **`-0.1051002149`**，ΔM21 = **`-0.0900910175`**）
  - 记忆与守卫：M lower = 20, M guard = 22, toneRegionMergeLower = 9
  - 约束审计：普通声母 D/F = 0/0，特殊族原子完整，火星韵组完整（splits = 0）
- **双特殊声族最优**：
  - `ch → S` ＋ `sh → P`
  - CKT：**`9.4601618671`**（ΔBase = -0.0964，ΔM21 = -0.0814）
  - 拓扑机制：`sh` 腾出主手主键 `S`，由 `ch` 接管，形成极低负荷卷舌音分布。
- **双完整韵组最优**：
  - `u(upper) → P` ＋ `u(home) → K`
  - CKT：**`9.4985210052`**（ΔBase = -0.0580，ΔM21 = -0.0430）
  - 拓扑机制：完全不扰动声母，仅移动两调区韵组即显著突破历史 M21 标杆。

### 4. 第三种子扩展审计（beam = 3，1312 候选总计）

引入一跳次优声侧候选 `sh → K`（`9.509299`）作为第三种子，总二跳空间扩充至 972 个组合（较双种子新增 319 个二跳组合，累计总评测达 1312 候选）：
- **第三种子最佳派生**：
  - `sh → K` ＋ `i-er(upper) → R`
  - CKT：`9.4803953458`（ΔBase = -0.0761，ΔM21 = -0.0611，M 20/22，D/F 0/0）
- **拓扑边界结论**：
  - 第三种子 `sh → K` 派生的所有候选均未能超越主种子 `sh → P` 构筑的协同最优（`9.4514302425`）。
  - 这证明了 `sh` 迁至 `P` 键所释放的主手 `S` 键具有不可替代的全局协同价值（无论由 `ch` 接管还是配合 `u` 占用 `K`，收益均系统性优于 `sh` 占用 `K`）。
  - 全局 5 点 Pareto 前沿在 1312 候选规模下保持高度稳固。
