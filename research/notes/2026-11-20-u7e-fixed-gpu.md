# UED 固定声母本机 GPU 长程退火

用户指定中心为 `UED-18c004bd1f31`。本轮只改变韵母，声母及 A/E/O 共 R 的载键均固定。硬约束为 M41、D2、无分支、Common399、实际 21×21、QZ/ZQ 双空桶，主码不占 AVUIO 辅键。

固定原稳健辅序：键道 `12/231/24`、三拼 `12/213/23`。`toneKeysByTone=IVUAO`、`shapeKeysByMeaning=AVUIO`、`toneDigitsByShapeMeaning=42310`。不同布局统一使用这套辅序，最终候选再检查 144 辅序及稳健性；长跑输出不是每个布局重新优化辅序后的成绩。

CKT v5.2 的字／二／三／四字词权重保持 1:3:1:1，键道／三拼等权，S005 分成员归一。1／2／3 倍都同时调整候选和参考的六项认知成本，运动成本保持不变。

## 执行

本机为 RTX 4060 Laptop 8GB。新无调 CUDA 适配器复用现有 CUDA resolve 内核，通过 include 使用原无调 CPU 评分器的模板解析、运动模型和 CPU 对照；原 CPU 文件没有改动。GPU 完成候选竞争排名与终码选择，CPU 负责编码、运动计价、汇总和独立核验，不能把本轮称为所有计算都在 GPU。

单个持久 CUDA 进程、batch=2、Rayon线程2、主动占空比25%。温度达到75°C或空闲显存不足1024 MiB时等待。8条链中4条主攻3倍、2条主攻2倍、2条主攻1倍；每链1200步周期，前400步粗扰动、后800步细扰动，再重热远跳。算子包括单韵迁移、韵交换、整键组交换、三韵轮换及多次组合。只检查最终布局合法性。

SQLite 事务同时保存缓存、链、完整 RNG 和批次；运行代码、评分器、二进制、输入合同 SHA-256 一致才可续跑。缓存保留最近约50000个状态、各目标前64项、链当前／最好布局及种子。导出三个成本轴各32项，属于有限代表集，不是完整历史 Pareto 前沿。

每100批次以及每个新成本轴冠军进行 GPU／CPU 核验；启动／恢复核验种子与不同当前状态。核验包括逐 outcome 和冻结 CPU 全轨比较。状态 JSON 原子写入；`search.sqlite` 是恢复真值，`frontier.json` 最多滞后20批，新冠军立即导出。PAUSE／温控等待不增加退火步数，但计入本次时长。

## 长跑与续跑

默认运行目录：`research/.cache/u7e-fixed-gpu-20261120`。从已验证的21批断点开始首段12小时。程序在隐藏窗口中运行，日志及 launch 记录保存在运行目录；即时进度见 `status.json`，候选见 `frontier.json`。

```powershell
just u7e-fixed-gpu-build
just u7e-fixed-gpu-test
just u7e-fixed-gpu-start
```

运行中仅创建 `PAUSE` 可暂停，移除后继续；创建 `STOP` 会在当前请求／批次后正常停止。再次启动前先确认旧进程已停止，移除该运行目录的 STOP，再执行相同 start 命令，从数据库恢复并增加新的12小时。不得删除断点以规避参数或哈希不一致。

本轮启动器的首次实机启动发现 PowerShell 参数数组的引号组合问题，Python未打开脚本，也未推进数据库；修正后再启动，保留失败日志用于诊断。最终启动确认见 `-launch.json`。

新工作目录可用 `just u7e-fixed-gpu-audit <目录>`、`just u7e-fixed-gpu-smoke <目录> 16`，再用同一目录续跑5批。实际运行仍依赖当前机器已冻结的 `.cache` 错误模型；模板另行归档于 `research/config/u7e-fixed-gpu-templates.json.gz`。正式长跑前不重生成配置，不改评分器二进制。原输入法生产文件和 R11 页面未改动。
