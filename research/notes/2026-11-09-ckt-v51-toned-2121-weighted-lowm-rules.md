# 带调 21×21：频权热点与低 M 拆分规则

## 结论

本轮把“不飞键”设成硬约束，并固定 `shapeKeysByMeaning=QOLAP`、词辅策略 `21/213/23`。结果推翻了“低 M 带调方案暂时打不过 QZ-e8f37a”的阶段性判断：允许少量普通声介整族例外后，约 M13 已经越过 QZ；约 M14 可降到 `9.518422`。

| 不做 `i/u/ü` 轮换 | 10 | 0 | 0 | 9.792063 |

## 不飞键口径

带调第二码的行本身表达调类，因此“韵母不飞键”不能解释成一个不带调韵母跨五调只用一个物理键；那会抹掉调。机器审计采用以下可实现口径：

- 同一声介族的所有合法音节第一码唯一；
- 同一 `(完整韵母, 调)` 的第二码唯一；
- 固定完整韵母规则只能整族改变列，五调仍按共享三行契约取行。

基线及本轮所有候选均通过审计：55 个声介族无第一码飞键，161 个带调完整韵母族无第二码飞键。

`di→K、shu→C` 以声介为原子，允许 `d/di/du`、`sh/shu` 分键。如果采用更严格的裸声母口径，即同一声母的所有介音形态也必须同键，当前小搜索的结果为：

- 单规则最好是 `r/ru: R→C`，`9.612618`；
- 两规则最好是 `x/xi/xv→C` 与 `s/su→N`，`9.627470`；
- 都改善 M12，但尚未打过 QZ。

## 频权方法

权重与 CKT v5.1 主目标对齐：字、二字词、三字词、四字词各自先按本轨频率归一，再按 `1:3:1:1` 加权；词中每个音节位置都计一次。因此总曝光单位为 `1×1 + 3×2 + 1×3 + 1×4 = 14`。

高曝光音节不等于最值得拆散的音节。例如 `shi4` 曝光最高，约占 1.761%，但其当前桶没有可由单音节迁移恢复的首选损失。按“理想迁移且不产生新碰撞”的代理，最突出的冲突包括：

| 同桶热点 | 单音节理想可恢复曝光 |
|---|---:|
| `da4 / dao4` | 各约 0.491% |
| `dou1 / duo1` | 各约 0.309% |
| `chu1 / si1` | 各约 0.279% |
| `dai4 / dian4` | 各约 0.274% |
| `jian4 / ju4` | 各约 0.272% |
| `neng2 / nian2` | 各约 0.260% |

整族理想分离代理中，韵身以 `an`、`ang`、`a/ao` 最突出；完整韵母以 `i`、`u`、`ian`、`ao`、`ou`、`an`、`in` 较突出。代理只用于召回，最终排名必须以完整 CKT 为准，因为键位运动和词码竞争会改变顺序。例如固定 `uang→第1列` 的碰撞代理很高，但完整 CKT 反而变差；固定 `ou→第3列` 才是当前单条固定韵冠军，达到 `9.626543`。

## `i/u/ü` 自由度

完整比较了鼻韵 `i,u∈{-1,0,+1}` 与 `ü∈{-2,0,+2}` 的 27 种组合：

| 规则 | M 估计 | CKT v5.1 |
|---|---:|---:|
| `i:-1,u:+1,ü:+2` | 12 | **9.659329** |
| `i:-1,u:0,ü:+2` | 12 | 9.662284 |
| `i:-1,u:+1,ü:-2` | 12 | 9.671225 |
| `i:-1,u:+1,ü:0` | 11 | 9.691027 |
| `i:0,u:0,ü:+2` | 11 | 9.715002 |
| 全部为 0 | 10 | 9.792063 |

所以：

1. `ü` 确实有 `±2` 自由度，但当前物理布局上 `+2` 明确优于 `-2`。
2. 取消 `u` 的性能代价极小，但在当前记忆语法里 `i` 与 `u` 不再组成一条对称规则，M 并不自动减少。
3. 真正减少一条规则时，最好的选择是保留对称 `i/u`、取消 `ü`。
4. 统一轮换并非唯一优解：同样约 M12，`i/u` 对称轮换 + 固定 `ou→第2列` 比原 M12 略好，达到 `9.653636`。

## 声介和韵侧的可用自由度

单条整声介规则的完整 CKT 前列为：

| 规则 | CKT v5.1 |
|---|---:|
| `di: D→K` | **9.586240** |
| `shu: X→C` | 9.593703 |
| `d: D→C` | 9.598448 |
| `di: D→N` | 9.600904 |
| `shu: X→N` | 9.611961 |
| `du: D→N` | 9.622776 |
| `jv: J→C` | 9.628768 |
| `ch: S→K` | 9.629121 |

这说明自由度不限于 `zh/ch/sh` 与零声母；频权后，`d/di/du`、`shu`、`jv` 都值得作为整族例外。当前最强两规则是 `di→K + shu→C`，在原 M12 韵语法下为 `9.521494`；换成“无 ü 轮换、固定 ou”的韵语法后进一步到 `9.518422`。

韵侧至少有四类低 M 语法可继续搜索：

1. **统一轮换**：当前 M12 的 `i/u` 对称偏移和 `ü:+2`。
2. **部分轮换**：只保留 `i/u`，或只保留 `i`、`u`、`ü` 中某些规则。
3. **固定完整韵母**：例如 `ou→第2/3列`、`ian→第2列`、`in→第5列`；规则直观且不飞键。
4. **韵身整体相对位移**：保留介音关系，整组移动 `o/n/...`；它与“固定完整韵母”必须分开命名和计 M。

其中两条易记候选尤其值得保留：

- **无轮换固定韵型**：不做 `i/u/ü` 轮换，只记 `ian→第2列`；加两声介例外后约 M13、`9.558864`。
- **对称轮换型**：只记 `i:-1/u:+1`；加两声介例外后约 M13、`9.554048`。

## 局限与下一步

M 是相对当前 M12 语法的规则计数：10 条非偏移规则，加保留的统一偏移规则、固定韵规则和声介例外。它适合比较本轮候选，但不是全局最小记忆证明。下一轮应：
