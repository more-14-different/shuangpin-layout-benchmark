# UED 固定声母长程 GPU 退火执行计划

目标：按用户指定，以 UED-18c004bd1f31 为中心，只退火韵母。本轮主目标为 3 倍认知成本 CKT v5.2，另保留 1／2 倍前沿。

沿用当前独立 worktree 和研究分支。固定声母、M41、D2、35 个韵母无分支、实际 21×21、Common399、QZ/ZQ 双空桶；固定 toneKeysByTone=IVUAO，shapeKeysByMeaning=AVUIO，42310。固定原稳健辅序：键道12/231/24、三拼12/213/23。候选和 S005 参考同时调整认知成本，运动不倍增。

方案取舍：旧带调 GPU 长跑使用其他主码／记忆／v5.1 合同，不能直接调用；既有无调 CPU 流评分器口径正确但不使用 GPU。本轮复用既有 CUDA resolve 内核，加独立无调 v5.2 适配二进制，保留旧评分源码和结果不变。

实现与验证：

- [x] 先写调度器测试，覆盖固定声母、记忆／键域／空桶约束、三倍参考归一及精确恢复。
- [x] 新二进制 include 冻结无调 CPU 实现，以相同模板接 CUDA；逐 outcome 核对通用 CPU，逐轨核对冻结 CPU，检查真实 CUDA launches。
- [x] SQLite 保存评分缓存、各链 RNG／当前状态／最好状态和批次；提交完成后原子导出 status、frontier。
- [x] 单 GPU 进程、batch=2、25% 占空比，75°C 或可用显存不足 1024 MiB 时等待；支持 PAUSE／STOP，不干扰其他研究进程。
- [x] 8 链（4条3倍、2条2倍、2条1倍），粗细轮换、重热及远距离重启；每个新成本点冠军和周期抽查通过 CPU 核验。
- [x] 完成种子审计、短跑和恢复检查，随后隐藏窗口启动首段12小时；确认真实运行、断点递增和状态可读后报告启动信息。

入围布局沿用现有 JS 完整评分器、独立 Python M-R2 和 144 辅序工具复核；不直接改生产布局。长跑的完成与产生改进分别记录，启动成功不视为已经探索完毕。

执行中由主代理自行实现和审阅；不派生代理。本轮用户已授权本机长程研究，12小时、资源限制和链数为执行者的具体运行选择。
