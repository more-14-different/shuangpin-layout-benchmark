# NF3 · 单首键声韵联合闭合

NF3 收录 315 个方案。所有方案在选型总览中按同一套筛选与授标规则处理；来源历史只作为出处和复核信息。单首键候选的 21 个普通声母各使用一个固定首键；零声母规则逐音节公开。

## 本版变化

- 修正 PR1 沿革：258 → 保留 221、移出 37、NF1 新建 16 → 237。
- NF2 从 42 个分档父种加入 39 个首键载体组变异端点，总计 276。
- NF3 从 49 个父种加入 38 个声韵联合端点，总计 314。
- 五类键域完成七类有限邻域检查，共 71,507,052 次动作检查、71,226 次完整条件评分。
- `S005` 从 PR1 快照恢复，保留 ch/zh 条件首键及完整冻结 benchmark；`S005-NF` 继续作为项目单首键派生版。二者在选型总览中不再单设历史对照卡，历史关系保留在方法页与方案详情中。
- “双拼布局：无尽的前沿”补入廿六双拼，并记录其 21×26 原版及 AEUIO/AVUIO 改版的种子作用。
- 页面保留布局、群聊立项、种子、模型四条时间线，以及五类键域探索地图。
- 发布摘要改为直白版本说明；筛选区采用莫兰迪蓝，测评环境采用莫兰迪灰，选型说明合并为紧凑信息块。
- README、snapshot 与审校材料由最终 HTML 核对。
- README 与 README_CN 自本次起只保留文字、表格和链接，不再内嵌图片；位图仅作本地审校，不上传至 GitHub 或 Gitee，SVG 不受此限制。
- 方案详情合并原“键盘与规则 / 音节码表与逐项频段 / 键频热力”三页；声韵映射与筛选热力、矩阵与合并明细现在共用频段和关键词筛选。
- 顶层页面改用各自有效的控制区：完整三组筛选仅留在“对比评测”；“选型总览”按正交结构维度选型；“方案详情”使用输入过滤与单选列表；“键对切片”只保留成本模型及条件场景。
- “选型范围 / 选型标记口径 / 键对切片口径”分别复用“筛选方案 / 标记怎样比较 / 当前测评环境”的语义色；键对切片口径移到对应子 Tab 导航之后。
- “方法与词典 → 阅读指南”重整为时间线、独立探索地图、双栏边界说明和独立 NF3 报告四层；增加表格、说明块及相邻章节之间的垂直间距。
- “我更在意”卡片改为独立青绿色系，偏好标签与下拉框、图例说明与入口分别同排居中；筛选联动文字用字重与斜体区分，并移除两条内部横向分隔线。
- 合并明细移除五个机械调码列、重复的原码/路径列和低价值原始桶；方案内导出连续包含键图、图例、当前筛选数据、编码规则与复核信息。
